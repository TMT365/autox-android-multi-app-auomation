## 使用风险

即使你的使用场景"看起来合理"，以下风险依然存在：

### 5.1 学术风险

- 大多数高校将"使用自动化脚本完成作业"明确列为**学术不端**
- 后果：课程成绩作废、学位撤销、记录入档案
- 部分学校已与学习通等平台联动，可直接定位违规账号

### 5.2 账号风险

- 学习通 / 豆包等 APP 已上线"无障碍自动化"检测模型
- 触发后果：账号封禁、设备封禁、IP 封禁
- 检测维度：
  - 无障碍服务异常调用频率
  - UI 操作模式（点击坐标过于规律）
  - 截图上传行为被识别为 OCR 工具调用
  - 与正常用户行为画像偏差过大

### 5.3 设备风险

- 反复截图 / 上传图片会消耗大量流量与电量
- 部分 ROM 会因 AutoX 长期在后台而发出"耗电警告"
- 不当配置可能导致系统卡顿、电池过热

### 5.4 法律风险

- 根据《中华人民共和国网络安全法》《数据安全法》，自动化批量操作
  在线平台可能涉嫌"非法获取计算机信息系统数据"
- 部分教育平台的服务条款明确禁止自动化操作，违反可能构成违约甚至侵权

### 5.5 道德风险

- 作业的目的是**学习与考核**，自动化完成会让学习机会流失
- 在你身边认真完成作业的同学，可能会因为你的"捷径"而感到不公平
- 你为节省的几十分钟，可能成为未来某次重要考试的薄弱基础
